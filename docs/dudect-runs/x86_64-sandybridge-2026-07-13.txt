Run 1 -- 2026-07-13  --all --samples 200000  (v1.0.0 software
                                              constant-time gate)
================================================================

  Full target set: the two harness sentinels, the four bitsliced-AES
  targets (key- and plaintext-varying, single and x4), the two scalar
  carry-less multiply targets, and the const_memcmp comparator added
  for the voleith 1.10.1 parity gate.

  sentinel_leak            |t| = 1421.38  FAIL  (expected sanity check)
  sentinel_clean           |t| =    1.21  PASS
  aes_ct64_encrypt_key     |t| =    0.12  PASS
  aes_ct64_encrypt_x4_key  |t| =    0.31  PASS
  aes_ct64_encrypt_pt      |t| =    0.34  PASS
  aes_ct64_encrypt_x4_pt   |t| =    0.55  PASS
  clmul64_scalar_b         |t| =    0.28  PASS
  clmul64_scalar_a         |t| =    0.57  PASS
  const_memcmp             |t| =    0.74  PASS  (new; parity gate)

  Notes:
    Clean run: the planted sentinel_leak fails (1421) and all eight real
    targets pass with wide margin (max real |t| = 0.74, const_memcmp).
    Every |t| trace walked around zero rather than scaling with sqrt(n),
    and class sigmas matched within ~0.3%, the signature of identical
    control flow across input classes.

    const_memcmp: class A compares equal 32-byte buffers, class B buffers
    that differ in one byte at a uniformly random position; the fixed
    length and the OR-accumulator (no early exit) make the running time
    independent of both equality and first-difference position.

    SHAKE / Keccak is not dudected: it is constant-time by construction
    (no S-box, no data table, no secret-indexed load, no secret-dependent
    branch), so there is no timing signal for the harness to detect.

Run 2 -- 2026-07-14  --all --samples 200000  (Grøstl core-primitive
                                              gate, voleith 1.10.1)
================================================================

  Grøstl-256 and Grøstl-512 one-shot targets, added when the Grøstl
  core primitive moved into ichor for the libtalos_syndrome
  designated-opener driver.  Class A hashes an all-zero 256-byte
  message; class B a uniformly random 256-byte message; the length is
  fixed across both classes, so a PASS certifies the digest time is
  independent of message content (the bitsliced SubBytes path has no
  secret-indexed table load).

  grostl256_input          |t| = 1.07  PASS
  grostl512_input          |t| = 0.49  PASS

  Notes:
    Both targets exercise the same bitsliced AES SubBytes path the
    aes_ct64 targets cover (Grøstl dispatches on the same feature bits;
    the dudect core is built with the hardware defines unset), now over
    the full Grøstl permutation and MixBytes/ShiftBytes layers.  Max
    real |t| = 1.07 (grostl256), well under the 4.5 threshold.

Run 3 -- 2026-07-31  per-target --samples 200000  (v1.1.0 gf2x
                                              circulant ring +
                                              fixed-weight sampler gate)
================================================================

  The six constant-time targets added for the 1.1.0 gf2x circulant ring
  (multiply, variable-amount rotation, the ct-select helper, Itoh-Tsujii
  inversion, support scatter) and the fixed-weight index sampler.  Each
  target was run on its own at the release-gate sample count.

  gf2x_mul_operand         |t| = 0.22  PASS
  gf2x_rotl_amount         |t| = 0.41  PASS
  gf2x_ct_select           |t| = 0.78  PASS
  gf2x_inv                 |t| = 0.23  PASS
  gf2x_scatter             |t| = 3.85  PASS
  sample_tape              |t| = 0.08  PASS

  Class definitions:
    gf2x_mul_operand  A: weight-1 operand; B: dense operand (fixed
                      multiplier).  Certifies the Karatsuba product and
                      reduction time is independent of operand weight.
    gf2x_rotl_amount  A: rotation amount k = 1; B: k = p - 1.  The barrel
                      of fixed public rotations selected by the bits of k
                      must not vary with k.
    gf2x_ct_select    A: selector bit 0; B: bit 1, over a full ring of
                      ichor_ct_select64 blends.  Guards against a compiler
                      lowering the masked select back to a branch on the
                      secret bit (the clang -O3 regression this helper
                      exists to prevent).
    gf2x_inv          A: the weight-1 unit a = 1; B: a dense odd-weight
                      unit.  Both classes are units, so the invertibility
                      check runs its full loop; the Itoh-Tsujii chain shape
                      is fixed by the public p.
    gf2x_scatter      A: support clustered at the low positions; B: the
                      same weight spread across the ring.  Every output
                      word and index is visited regardless of the support.
    sample_tape       A: a fixed 0x5a reference tape; B: a fresh random
                      tape each trial (lambda 256, w = 261, n = 86902).
                      The overlay Fisher-Yates and Lemire reduction consume
                      the tape at a fixed rate with no rejection loop.

  Notes:
    Clean run: all six targets pass at the 200000-sample release gate,
    max real |t| = 3.85 (gf2x_scatter), under the 4.5 threshold.  Scatter
    is the noisiest target: its O(words * w) double loop over the dense
    output gives it a variant, run-to-run statistic (a re-measurement read
    2.04), but the per-class means track to within 0.15% (337453 vs 337069
    cycles) and it stays clear of threshold.  Gracemont shows the same
    variance and interpretation (see that host's Run 3 note).

    gf2x_inv exercises gf2x_equal only on the always-equal unit path (both
    classes are units); the invertibility check's early-return branch
    fires only on a non-unit resample and is not covered here (see
    ../SECURITY_REVIEW_1_1_0.md, finding L-1).
